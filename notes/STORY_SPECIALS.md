# Gen 3 specials, commands and sounds -> Black 2 field scripts (researched 2026-10-06)

What every `special`, the 80 most used other script commands, and every sound of Sapphire's story scripts become in a
Black 2 field script. Counted over pokeruby's `data/maps/*/scripts.inc` (370 files), `data/scripts/*.inc` (35) and
`data/event_scripts.s` (406 files in all), **Sapphire build**: `.ifdef SAPPHIRE` branches kept, Ruby-only branches and the
`.if DEBUG` file `data/scripts/debug.inc` dropped (counting it would add e.g. 262 `additem`, 154 `adddecoration`).
Movement-list macros (`walk_up`...) are counted apart (2c). Counts and tables were generated by throw-away scripts in the
session scratchpad (not kept).

**Tags.** [evidence] = a Black 2 script uses the command the same way, or the decomp handler / CTRMapV brief says so
(the Evidence column gives it). [evidence: story_infra movement probe] = verified in the emulator on 2026-10-06 by the
story_infra movement probe. [guess] = no B2 use found for that situation; reasoned from names, argument kinds or absence
of a command.

## Surprises worth knowing

- The decomp's own header comment for `CMP_STACK` is wrong: the handler jumps when the popped value is **not** 1.
- `YesNoWin` returns 0 for YES (Gen 3: 1). `ListMenu` cancel is 65534 (Gen 3: 127).
- `ActorDelete` does not set the hide flag (Gen 3 `removeobject` does), so a forgotten `FlagSet` makes NPCs come back.
- Global 2805 (the `giveitem` replacement) overwrites 0x8010; take the bag-space result from your own `ItemCheckSpace`
  before the call [evidence: story_infra movement probe].
- The "!" emote (movement 75) plays its own sound, so Gen 3's `playse SE_PIN` before it is dropped; Gen 3's "turn on the
  spot" (`walk_in_place_fastest_*`) is B2 40-43, not the much more common 32-35 (normal-speed walk in place) [evidence:
  story_infra movement probe].
- `PlayFieldEffect 63`/`64` shows the Pokédex over the player (boy/girl; Bianca's Pokédex hand-over), not a generic
  key-item pose [evidence: story_infra movement probe; b2:0854.s:438-449].
- `checkpartymove` and `PokePartyHasMoveAny` share the "6 = nobody knows it" convention, and `checkplayergender` /
  `TrainerCardGetSex` share 0 = boy - two of the few 1:1 commands.
- B2 has a real "NPC follows the player" system (`ActorPairSet actor, pair, isGlobal, trainer, script` / `ActorPairEnd`,
  ctr 0x250-0x251) that Gen 3's "follow me" walks never had; it could replace long scripted escort movements.
- B2's sound archive already contains Hoenn battle themes (`SEQ_BGM_VS_RS_LEADER`, `SEQ_BGM_VS_RS_CHAMP`, for the PWT) and a
  "lead the player" theme (`SEQ_BGM_E_TSURETEKE2`), but no "help!" or "Team Aqua appears" theme - those need stand-ins
  (`SEQ_BGM_E_PLASMA`) or imported songs.
- Gen 3 `MUS_HEAL` has no single B2 twin: B2 uses `SEQ_ME_ASA` after a fade for "rest" heals and the Pokémon Center
  sequence plays its own jingle.
- `PlayerGetDir` must be called explicitly; there is no `VAR_FACING` filled in for you.
